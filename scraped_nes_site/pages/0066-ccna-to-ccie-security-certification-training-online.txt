Course Duration:
CCNA:
The foundation of networking in this module, you will learn the foundational concepts of networking. You will cover topics such as network protocols, network design, and network troubleshooting. By the end of this module, you will be able to configure and troubleshoot basic network infrastructure.
CCNP Enterprise:
Advanced enterprise networking concepts in this module, you will learn advanced enterprise networking concepts. You will cover topics such as routing protocols, WAN technologies, and advanced network design. By the end of this module, you will be able to design, implement and troubleshoot complex enterprise networks.
CCNP Security:
Advanced security concepts in this module, you will learn advanced security concepts. You will cover topics such as security protocols, access control, and threat mitigation. By the end of this module, you will be able to design and implement secure networks.
CCIE Security:
Expert-level network security in this module, you will learn expert-level network security concepts. You will cover topics such as network security design, risk assessment, and threat mitigation. By the end of this module, you will be able to design and implement secure enterprise networks.
