VXLAN (Virtual Extensible LAN) and EVPN (Ethernet VPN)
are two of the most popular technologies used in network virtualization. VXLAN is a tunnelling protocol used to create virtual networks over an existing physical network, while EVPN is a mechanism used to extend layer 2 and layer 3 connectivity between different locations.
Here's a breakdown of the key concepts you'll learn about in our VXLAN-EVPN course:
Network Virtualization
: You'll learn about the benefits of network virtualization, including improved scalability, flexibility, and agility.
VXLAN
: You'll learn about VXLAN technology and how it works, including
VXLAN packet format, VXLAN VTEPs (VXLAN Tunnel Endpoints), and VXLAN configuration
.
EVPN
Cisco: You'll learn about EVPN technology and how it can be used to extend layer 2 and layer 3 connectivity between different locations. You'll also learn about EVPN types, MAC learning, and ARP suppression.
VXLAN-EVPN Integration
: You'll learn about how VXLAN and EVPN can be integrated together to provide a complete network virtualization solution. You'll learn about different deployment scenarios, including spine-leaf architecture and VXLAN-EVPN with BGP.
Troubleshooting
: You'll learn how to troubleshoot common issues that may arise when working with VXLAN and EVPN, including
VTEP connectivity issues, routing issues, and multicast issues
.
